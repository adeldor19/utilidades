# Utilidades ProfeAlbertoD

Pequeño espacio de herramientas docentes para diseñar experiencias de aprendizaje y reutilizar materiales de aula.

## Áreas

### 1. Diseño de aprendizaje
- Diseñador de retos competenciales
- Secuenciador de sesiones
- Adaptador de actividades DUA
- Actividades de salida

### 2. Recursos reutilizables
- Banco de actividades y proyectos
- Buscador de recursos
- Biblioteca de plantillas
- Conversor de formatos

## Estado actual

La portada inicial está publicada en `index.html`. Las herramientas aparecen como propuestas planificadas; todavía no están implementadas.

## Publicación con GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona la rama `main` y la carpeta `/(root)`. Guarda los cambios. La web se servirá en:

https://adeldor19.github.io/utilidades/

## Enfoque técnico inicial

- HTML y CSS sin dependencias de compilación.
- JavaScript nativo para las herramientas interactivas.
- Prioridad al almacenamiento local y a la importación/exportación de copias de seguridad.
- No introducir datos personales del alumnado en servicios externos sin valorar privacidad y seguridad.

## Separación de proyectos

El gestor de rúbricas seguirá siendo una herramienta independiente.
